# Building photo URL resolution

Module: [`ExpoApp/services/buildingPhotoUrl.js`](../ExpoApp/services/buildingPhotoUrl.js)

Used by [`ExpoApp/services/nearbyPublicBuildings.js`](../ExpoApp/services/nearbyPublicBuildings.js) to populate each picker option’s **`photoUrl`**, which becomes **`buildingImageUrl`** on new posts and **`buildings[].image`** in context.

See [nearby-public-buildings.md](./nearby-public-buildings.md) for the full tag list, Wikidata batching, User-Agent, and licensing notes.
